# discus-analysis

An interactive physics model of a discus throw, built to answer one question:
why do elite throwers release the discus with a *negative* angle of attack,
when a discus makes zero lift at α = 0 and negative lift below it?

`DiscusAngleOfAttack.jsx` is the source: a self-contained React component
(RK4 trajectory integration + lift/drag/moment coefficient curves fit to
published wind-tunnel behaviour, four linked SVG charts, a validation panel
checked against values from the literature, and a caveats section spelling
out what's published vs. tuned vs. left out).

## Published version

The component is published as a mobile-viewable POC at
[`docs/discus-analysis/`](../docs/discus-analysis/) — live at
`https://espenhk.github.io/espenhk-hobby-projects/discus-analysis/` once
merged to `main`. That's a single self-contained `index.html` loading React,
ReactDOM, Babel (for in-browser JSX) and Tailwind from CDN, per the
"hand-written frontend" convention in `docs/README.md` — no build step. It's
generated by hand from this source file rather than by a build script, so if
you edit `DiscusAngleOfAttack.jsx`, port the change into
`docs/discus-analysis/index.html`'s inline `<script type="text/babel">`
block too.
